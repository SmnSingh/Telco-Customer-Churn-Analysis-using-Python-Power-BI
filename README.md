# 📊 Customer Churn Analysis – Python & Power BI

An interactive **Customer Churn Analysis** project built using **Python and Power BI** to analyze customer behavior, identify churn patterns, and generate actionable insights for customer retention.

---

## 📌 Project Overview

This project analyzes customer churn across **contract types, tenure, internet services, payment methods, and customer segments**.

Python was used for **data cleaning and exploratory analysis**, while Power BI was used to create an **interactive dashboard** with KPIs, slicers, and visualizations.

---

## 🎯 Project Objectives

- Analyze overall customer churn and retention.
- Identify customer segments with higher churn.
- Compare churn across contract types.
- Analyze churn by internet service and payment method.
- Understand the relationship between tenure and churn.
- Build an interactive Power BI dashboard.
- Generate insights to support customer retention strategies.
