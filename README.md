Customer Churn Analysis using Python and Power BI

📊 Project Overview

Customer Churn Analysis is an interactive data analytics and visualization project developed using Python and Microsoft Power BI. The project analyzes customer behavior, identifies churn patterns, and highlights customer segments that may require retention strategies.

The Power BI dashboard transforms customer data into meaningful business insights through KPIs, interactive slicers, and comparative visualizations. It is designed to help businesses understand why customers leave and which customer groups have higher churn.

🎯 Project Objectives

Analyze overall customer churn and retention patterns.

Identify customer segments with higher churn.

Compare churn across different contract types.

Analyze churn based on internet service providers.

Understand how customer tenure relates to churn.

Compare churn across different payment methods.

Present insights through an interactive and easy-to-understand Power BI dashboard.

Provide business recommendations that can support customer retention strategies.
